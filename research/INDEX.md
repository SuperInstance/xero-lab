## Read this first — the framing

**Zero is the blank page.** It is already an agent — an iteration
engine with an alarm contract — at limitless potential, before
anything is added. **Everything in this library is an ADDITION**: a
plug-in layer, a pattern you may call on, a platform's limits, a
practice worth borrowing. The first addition is the first
constraint: the model of understanding built on top of the blank
page. No file here is a component of Zero, and Zero does not need
any of them to be what it is. `nuggets.md` is the one exception in
kind — it records what Zero itself is; the rest record what may be
added to it.

## How to use this index

Each row is an address: **topic → file → gist → confidence**. When a
design question comes up, find its row, open the file, and use its
"patterns worth calling on" and "open questions" sections. Files end
with a status line; anything unverifiable is marked UNVERIFIED
inside the file itself.
