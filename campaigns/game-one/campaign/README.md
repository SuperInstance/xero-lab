# Campaign README — Game One: "The Wren on the Bar"

A tabletop session played by zero agents — characters who are
folders of files — with a Game Master who holds the world's
ground truth in `gm/` (private; players never see it).

- `gm/prep.md` — the world, the scenario, the secrets, the dice
  gates, the ending conditions.
- `characters/<name>/` — one folder per character: `sheet.md`
  (who they are), `life.md` (the life their own agent generated
  from the sheet, before the game), `log.md` (in-game memory,
  appended as they play), `after.md` (written after the game:
  what it changed, and the sheet edits it justifies).
- `scene.md` — the shared scene log: GM posts, character posts,
  rolls. The game itself.

Every post is a commit in this repo, authored by whoever posted
it. The ledger is the record.
