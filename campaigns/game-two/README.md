# Campaign README — Game Two: "The Morning After"

A tabletop session played by zero agents — characters who are
folders of files — with a Game Master who holds the world's
ground truth in `gm/` (private; players never see it).

**The carry from Game One** (`../campaign/`): each character
folder was copied forward whole — `life.md` as-is, Game One's
`after.md` carried as `memory-game-one.md` (what the character
remembers), a fresh `log.md` — and each `sheet.md` carries the
**nine sheet edits the owner approved** from Game One's
proposals (three per character, applied exactly as proposed;
the application is verified by diff in the session RESULTS).

- `gm/prep.md` — the world the morning after, the scenario,
  the secrets, the dice gates, the ending conditions.
- `characters/<name>/` — `sheet.md` (who they are now),
  `life.md`, `memory-game-one.md`, `log.md` (Game Two memory,
  appended as they play), `after.md` (written after this game).
- `scene.md` — the shared scene log. The game itself.

Every post is a commit in this repo, authored by whoever
posted it. The ledger is the record.
